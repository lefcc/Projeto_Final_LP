# Sistema de Gerenciamento de Livros

## Objetivo
Este projeto é um sistema desenvolvido para gerenciar livros.  
O usuário pode cadastrar livros, listar todos, buscar por título e remover registros.

## Estrutura do Projeto
- **main.c**: contém o menu principal e chama as funções.  
- **livro.h**: possui a estrutura Livro e as declarações das funções.  
- **funcoes.c**: implementa as funcionalidades do sistema.  
- **README.md**: documentação do projeto.
- **dados_livros**: é nele que fica salvo as informações dos livros cadastrados

## Funcionalidades
O sistema permite:
- Cadastro de livros  
- Listagem de todos os livros  
- Busca por título  
- Remoção de livros  
- Encerramento do programa


## Observações
Os dados dos livros são armazenados em um arquivo de texto para que não sejam perdidos ao fechar o programa.
